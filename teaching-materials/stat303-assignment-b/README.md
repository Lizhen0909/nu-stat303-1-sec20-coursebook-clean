# Assignment B project kit

Extract the entire folder and open `stat303-assignment-b` in VS Code. Work in `assignment_b.ipynb`, keeping it beside `data/`.

Complete instructions, points, and submission requirements are on the coursebook Assignment B page:
https://lizhen0909.github.io/nu-stat303-1-sec20-coursebook-clean/Assignment%20B.html

The CSV contains six fictional library-branch visit counts for one illustrative day. It is not a real survey. Pandas and plotting code are supplied so the assignment assesses your setup workflow and interpretation.

Create this project's own `.venv` and `requirements.txt` as directed. Do not copy the practice environment or submit it. The notebook starts without saved outputs or completed answers.
