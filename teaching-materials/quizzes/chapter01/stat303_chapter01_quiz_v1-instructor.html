Question 1: Open the practice project (1 point(s))

You downloaded the setup practice kit and want to work on activity01.ipynb with its related files visible in VS Code. Which approach follows Chapter 1?

A. Open the notebook directly inside the ZIP viewer and leave the kit compressed.

B. Extract the kit and use File → Open Folder to open the extracted stat303-setup folder. (Correct answer)

C. Move the notebook out of the kit and open only that file, leaving the related files behind.

D. Use File → Open Folder to open the folder containing the Python executable.

Rationale: Opening the extracted project folder keeps the notebook and related files together and visible in Explorer. The Python installation folder is not the project folder.

Question 2: Verify the notebook Python (1 point(s))

You select your familiar STAT201 Python installation using Python: Select Interpreter. Your open notebook still prints an executable path belonging to a different installation. What should you do?

A. Assume the notebook is correct because selecting an interpreter automatically changes every open notebook kernel.

B. Choose whichever kernel has the highest Python version number, regardless of its path.

C. Install another copy of Python before checking the available notebook kernels.

D. Use the notebook kernel picker to select the intended environment, then rerun the cell that prints sys.executable. (Correct answer)

Rationale: Workspace interpreter selection and notebook kernel selection are separate. The executable path printed by the notebook verifies which Python actually runs its cells. Chapter 1 uses a familiar existing environment, not a required new .venv.

Question 3: Choose the right cell type (1 point(s))

You have a code cell that calculates the mean of three readings. You now want to add a heading and a paragraph explaining the calculation in your report. What should you use?

A. A Markdown cell for the heading and explanation, while keeping the calculation in a code cell. (Correct answer)

B. A Python code cell containing the paragraph as ordinary text without quotes or comments.

C. The terminal, because text entered there automatically becomes part of the notebook.

D. Only a Python comment, because Markdown cells cannot display explanations alongside code.

Rationale: Markdown cells provide formatted narrative and headings. Code cells perform computations. Terminal text is not automatically saved as notebook content.

Question 4: Check that the notebook runs from the beginning (1 point(s))

Your mean calculation worked, but you then deleted the earlier cell that defined readings. The old result is still visible. What is the best check before considering the notebook complete?

A. Keep the old output; a visible result proves the current cells still run successfully.

B. Run only the mean calculation again without restarting, since the kernel may remember readings.

C. Restart the kernel and run all remaining code cells in order; restore the missing definition if needed, then save the successfully rerun notebook. (Correct answer)

D. Save and reopen without rerunning; saved output proves that every required definition is present.

Rationale: A running kernel can retain values from deleted cells, and a notebook can retain saved output. Restarting and running all cells checks that the current notebook includes the definitions it needs.
