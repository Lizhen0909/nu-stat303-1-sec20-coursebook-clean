Question 1: Interpreting dimensions (1 point(s))

After a default CSV import, movies.shape is (2228, 11). What does this tell you?

A. There are 2,228 movies and 11 data columns; the row index is not one of the 11 columns. (Correct answer)

B. There are 2,228 movies and 10 data columns plus the row index.

C. There are 11 movies and 2,228 variables.

D. Only the 5 rows shown by head() were imported.

Rationale: shape reports data rows and columns, excluding the index.

Question 2: Selecting a variable (1 point(s))

You assign ratings = movies['IMDB Rating']. Which description is correct?

A. ratings is a two-dimensional DataFrame with 11 columns.

B. ratings is a Python list without row labels.

C. ratings is a one-dimensional Series that retains the corresponding row labels. (Correct answer)

D. ratings is the mean rating as a single number.

Rationale: Selecting one named column with a single pair of brackets produces a Series.

Question 3: Diagnosing an import (1 point(s))

A text file header is Title;Year;Rating. Reading it with the default pd.read_csv() returns one column named Title;Year;Rating. What is the best next step?

A. Use head(3) to split the column into three variables.

B. Read it again with sep=";", then inspect its shape and column names. (Correct answer)

C. Rename the file to .csv; pandas will then infer three columns from the extension.

D. Use index_col=0 to separate the three variables.

Rationale: The semicolon delimiter must be parsed; a successful function call alone does not prove the table was read correctly.

Question 4: Preserving the intended columns (1 point(s))

movies has a default RangeIndex containing only row numbers. You want a CSV with its existing data columns and no extra row-number column. Which export fits that goal?

A. movies.to_csv("movies_export.csv", header=False)

B. movies.to_csv("movies_export.csv", index=True)

C. movies.to_csv("movies_export.csv", sep=";")

D. movies.to_csv("movies_export.csv", index=False) (Correct answer)

Rationale: index=False omits the row index; meaningful IDs stored in an index would need to be preserved when required.
